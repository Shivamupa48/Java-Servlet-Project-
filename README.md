# Java Servlet Projects

This repository contains a collection of Java web projects developed using **Java Servlets**, **JSP**, **HTML/CSS**, and in some cases, **JDBC with DAO & Utility classes** for database operations.

## 📁 Projects Overview

### 1. 🌦 Weather App
A dynamic weather web application that:
- Uses **OpenWeatherMap API** to fetch real-time weather data.
- Accepts user input (city name) and displays:
  - Temperature (°C)
  - Humidity
  - Wind Speed
  - Weather Conditions
- Technologies: **Servlet**, **JSP**, **HTML/CSS**, **JavaScript**, **API Integration**.

### 2. ➕ Simple Calculator
A basic calculator web app that:
- Performs **addition, subtraction, multiplication, and division**.
- Takes input via HTML form and processes using Java Servlet.
- Displays the result dynamically.
- Technologies: **Servlet**, **JSP**, **HTML/CSS**.

### 3. 🔐 Login & Register System (with DB Integration)
A user authentication system that:
- Allows users to **register and log in securely**.
- Uses **DAO pattern** and **Utility classes** for DB access.
- Stores user credentials in a **MySQL database** using **JDBC**.
- Technologies: **Servlet**, **JSP**, **HTML/CSS**, **JDBC**, **DAO**, **MySQL**.

---

## 🛠 Technologies Used
- Java Servlets & JSP
- HTML5, CSS3
- JDBC & MySQL (for Login System)
- OpenWeatherMap API (for Weather App)
- MVC Architecture (basic separation of concerns)
- Apache Tomcat (for deployment)
